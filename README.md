# 🎬 Bảng Phân Cảnh AI (AI Storyboard Studio)

Hệ thống tự động hóa chuyển đổi **Kịch bản nói (Voiceover + Mô tả cảnh)** và **Ảnh bối cảnh gốc** thành **Bảng Phân Cảnh Điện Ảnh 9:16** tương tác đa tầng (15 Micro-beats).

## 🌟 Tính Năng Cốt Lõi
- 🔰 **Băm nhỏ kịch bản:** Tự động chia mỗi cảnh thành 3 beat (Đầu cảnh, Cao trào chi tiết, Mồi chuyển cảnh Match-cut).
- 🖼️ **Lưu trữ R2 Cloudflare:** Toàn bộ ảnh phân cảnh chất lượng cao được lưu trữ trên Cloudflare R2 CDN tốc độ cao.
- 📱 **Giao diện HTML Studio Mobile-First:** Tối ưu hóa UI/UX, hỗ trợ xem Timeline, phóng to Lightbox và in báo cáo PDF.
- 🤖 **Tích hợp Nova Telegram Bot:** Nhận kịch bản + ảnh từ Telegram, tự động xử lý và trả về link GitHub Pages trực tuyến.
